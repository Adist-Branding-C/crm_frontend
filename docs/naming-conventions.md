| Type      | Convention           | Example             |
| --------- | -------------------- | ------------------- |
| Folder    | kebab-case           | `lead-management`   |
| Component | PascalCase           | `LoginPage.tsx`     |
| Hook      | camelCase + use      | `useLeadFilter.ts`  |
| Service   | kebab/camel + suffix | `lead.service.ts`   |
| Constants | kebab + suffix       | `lead.constants.ts` |
| Types     | kebab + suffix       | `lead.types.ts`     |
| Utils     | helper/action naming | `leadHelpers.ts`    |
