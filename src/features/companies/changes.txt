        3) Naming conversiton also very imporant

          I can see some code in  CompaniesPage Component but its wrong naming because the naming should be
           
                    Noun (Most common)

                    Used when the component represents a UI element which are sharedbale across entire website.

                    Button.jsx
                    Modal.jsx
                    Card.jsx
                    Avatar.jsx
                    Sidebar.jsx
                    Header.jsx

                    2. Modifier + Noun

When there are multiple variations.

PrimaryButton.jsx
UserCard.jsx
ProfileAvatar.jsx
SuccessAlert.jsx
LoadingSpinner.jsx


3. Domain + Noun

For large applications.

LeadCard.jsx
LeadTable.jsx
LeadFilters.jsx
InvoiceList.jsx
CustomerModal.jsx

4. Verb (Action) + Noun

Use this when the component performs a specific action, typically a dialog, form, or workflow.

CreateLeadModal.jsx
EditLeadForm.jsx
DeleteUserDialog.jsx
UploadFileModal.jsx
InviteMemberDrawer.jsx

This is much clearer than just ActionFrame.
